# Workout Tracker v6
- Editable local timers.
- Tracks actual reps completed for each set.
- Adaptive set defaults: if the previous session was not completed at the target, today starts one rep lower for that set (minimum 1).
- Example: previous attempt was 4 reps and target was not achieved -> today defaults to 3 reps.
- History remains editable and separate from timer settings.
